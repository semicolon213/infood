# SRS (소프트웨어 요구사항 명세서)

**시스템명:** 재고콕 — 소상공인용 식자재 재고 관리 및 AI 메뉴 추천 시스템
**문서 버전:** v0.2
**작성일:** 2026-10-27

---

## 1. 소개

### 1.1 목적
본 문서는 재고콕 시스템의 기능·비기능 요구사항, 외부 인터페이스, 데이터 요구사항을 정의한다. 개발, 테스트, 평가의 기준 문서로 사용한다.

### 1.2 범위
- 포함: 재료·메뉴 관리, 명세서 사진·바코드 입고, 기한 계산, 판매 연동 차감, 대시보드, AI 메뉴 추천, 폐기 기록, 라벨 날짜 인식(확장)
- 제외: POS 연동, 결제, 자동 발주, 다중 매장·직원 권한, 네이티브 앱

### 1.3 용어 정의

| 용어 | 정의 |
|---|---|
| 재료 (Ingredient) | 매장에서 관리하는 식자재 품목 (예: 양파) |
| 묶음 (Lot) | 한 번에 입고된 같은 재료 단위. 기한과 잔량을 가진다 |
| FEFO | First Expired, First Out. 기한이 빠른 묶음부터 차감 |
| 기본 보관일수 | 재료별로 설정한, 기준일로부터 사용 권장 기한까지의 일수 |
| 기준일 | 기한 계산의 출발 날짜 (입고일, 제조일, 산란일, 포장일, 도축일) |
| 명세서 | 거래처 납품 시 받는 거래명세서·영수증 |
| 매핑 | 바코드 또는 명세서 품목명과 매장 재료의 연결 |

### 1.4 참고 문서
- 전체 문서 목록과 담당 범위: 루트 `README.md`의 문서 절

## 2. 전체 설명

### 2.1 제품 관점
독립형 웹 서비스. Next.js 서버가 Supabase(DB·인증·파일), Claude API(인식·추천), 식약처 바코드 API, (선택) 축산물 이력제 API와 연동한다.

### 2.2 사용자 특성
| 사용자 | 특성 |
|---|---|
| 매장 운영자 | 스마트폰 사용 능숙, PC 사용 적음, 주방에서 짧게 사용, IT 용어에 익숙하지 않음 |

### 2.3 제약 사항
- C-01: 모바일 브라우저(iOS Safari, Android Chrome) 최신 2개 버전을 지원한다.
- C-02: 카메라 사용을 위해 HTTPS로 서비스한다.
- C-03: 외부 API 인증키는 서버에서만 사용하고 클라이언트에 노출하지 않는다.
- C-04: 개발 기간 5주, 인원 3명.

### 2.4 가정 및 의존성
- A-01: 식약처 바코드 API는 제품 단위 정보를 제공하며 개별 포장 날짜는 제공하지 않는다.
- A-02: 판매 데이터는 사용자가 하루 단위로 직접 입력한다.
- A-03: 시스템이 계산한 기한은 매장 기준 권장 기한이다.

## 4. 비즈니스 규칙

### BR-01 기한 계산 우선순위
```text
1. 사용자 직접 입력                    → expires_at = 입력값                  (source=manual)
2. 라벨 소비기한                        → expires_at = 라벨 날짜               (source=label)
3. 라벨/API 기준일(제조·산란·포장·도축)
   3-1. 기간 정보 있음                  → expires_at = 기준일 + 기간           (source=label|api)
   3-2. 기간 정보 없음                  → expires_at = 기준일 + 기본 보관일수  (source=label|api)
4. 기준일 없음, API 기간만 있음         → expires_at = 입고일 + 기간           (source=api)
5. 정보 없음                            → expires_at = 입고일 + 기본 보관일수  (source=default)
-  기한 추적 제외 품목                  → expires_at = null
```
- 기간은 일·월·년 단위로 다룬다. 월·년은 달력 기준으로 더하고, 해당 일이 없으면 그 달 말일로 맞춘다 (예: 1/31 + 1개월 = 2/28).
- 날짜 계산은 서버 코드에서만 수행한다. AI는 날짜·유형·기간 문구 추출만 담당한다.

### BR-02 FEFO 차감
- 차감 대상 묶음: 해당 재료의 잔량 > 0 묶음
- 정렬: `expires_at` 오름차순(null은 마지막) → `received_at` 오름차순
- 앞 묶음부터 잔량을 차감하고 묶음별 `use` 이동 이력을 남긴다.

### BR-03 단위 환산
- 재고는 재료의 기본 단위(g/ml/ea)로 저장한다.
- 환산표: kg→g ×1000, L→ml ×1000. 그 외 단위(단, 박스, 판 등)는 사용자 입력 환산 계수를 사용한다.

### BR-04 AI 결과 반영 원칙
- AI가 생성한 데이터는 사용자 확인 없이 재고·재료·메뉴에 반영하지 않는다.
