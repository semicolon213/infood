## 1. 추진 배경과 필요성

- 소형 외식업장은 재고를 체계적으로 관리하지 않아 **기한 경과 폐기**와 **감에 의존한 발주**가 반복된다.
- 기존 재고 관리 앱은 **입력 부담**이 커서 바쁜 사장님이 계속 쓰기 어렵다.
- 비전 AI와 공공 식품 데이터(식약처 바코드 API)를 함께 쓰면 **입력을 대부분 자동화**할 수 있다.
- 2023년 소비기한 표시제 시행으로 기한 관리에 대한 관심이 높아졌다.

## 2. 추진 목적

1. **입력 자동화:** 명세서 사진과 바코드로 입고 입력 시간을 크게 줄인다.
2. **기한 가시화:** 입고 묶음 단위로 기한을 추적해 임박 재료를 놓치지 않게 한다.
3. **폐기 감소:** 임박 재료를 소진하는 메뉴를 추천해 폐기 비용을 줄인다.

목표치는 `01_PRD.md` 3장 참고.

## 3. 차별성

| 기존 방식·서비스 | 재고콕 |
|---|---|
| 품목·수량을 손으로 입력 | 명세서 사진·바코드로 자동 입력, 사람은 확인만 |
| 재료별 총량만 관리 | **입고 묶음별 기한 추적** |
| 재고와 판매가 분리 | 판매량 입력 시 **레시피 기반 자동 차감** |
| 임박 알림에서 끝 | 임박 재료로 **무엇을 만들지까지 추천** |

## 4. 기술 스택

| 영역 | 기술 | 선택 이유 |
|---|---|---|
| 프레임워크 | Next.js (App Router), TypeScript | 프론트·서버를 한 저장소, 한 번의 배포로 |
| UI | Tailwind CSS, shadcn/ui, Recharts | 모바일 관리 화면을 빠르게 구성 |
| 검증 | react-hook-form, Zod | 폼 검증과 AI 응답 검증에 같은 스키마 사용 |
| 데이터 | Supabase (Postgres, Auth, Storage, RLS) | 관계형 재고 데이터, 매장별 데이터 격리 |
| AI | Vercel AI SDK + Claude API | 사진 인식 결과를 정해진 JSON 형식으로 받음 |
| 바코드 | @zxing/browser | iOS Safari 포함 휴대폰 카메라 스캔 |
| 외부 데이터 | 식약처 바코드연계제품정보 API, (선택) 축산물 이력제 API | 무료 공공 데이터 |
| 테스트 | Vitest, Playwright, MSW | 재고 계산 로직 검증, 모바일 E2E |
| 배포 | Vercel, GitHub | PR마다 미리보기, HTTPS 기본 제공(카메라 필수 조건) |

설계 결정의 근거는 `06_ARCHITECTURE.md` 13장 참고.

| 공동 | 매장 인터뷰, 통합 테스트, 발표 |

## 6. 추진 단계

조사·설계(1주) → 재고 기본기(2주) → 입고 자동화(3주) → 추천·대시보드(4주) → 마무리·발표(5주). 마일스톤과 상세 일정은 `05_일정표.md`, 작업 분해는 `04_WBS.md` 참고.

## 7. 기대 효과

- **사장님:** 입고 입력 시간 단축, 폐기 비용 감소, 메뉴 결정 부담 완화
- **사회:** 음식물 폐기 감소에 기여
- **기술:** 비전 AI, 공공 데이터, 업무 로직(선입선출, 기한 계산)을 결합한 실용 사례

## 8. 리스크와 대응

> 프로젝트 리스크는 이 표에서만 관리한다.

| 리스크 | 영향 | 대응 |
|---|---|---|
| 손글씨 명세서 인식률 저하 | 입고 자동화 가치 감소 | 확인 화면 필수, 수동 입력으로 대체, 시연은 인쇄된 명세서 |
| 바코드 API 조회율 낮음 | 바코드 기능 가치 감소 | 1주차에 조회율 측정, 낮으면 재료 등록 보조로 축소 |
| 외부 API 인증키 발급 지연 | 바코드 개발 지연 | 1일차 신청, 지연 시 목(mock) 데이터로 개발 |
| AI가 없는 재료로 추천 | 신뢰도 하락 | 서버에서 재료·재고 검증 후 노출 |
| 단위 불일치 (kg, 단, 박스) | 재고 오차 | 재료별 기본 단위, 애매한 단위는 사용자가 환산 계수 입력 |
| AI 비용 초과 | 개발 중단 | 매장별 일일 호출 한도, 개발·테스트는 고정 응답 사용 |
| 일정 지연 | 핵심 기능 미완성 | `04_WBS.md` 컷라인 순서대로 축소 |
