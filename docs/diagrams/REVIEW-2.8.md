# 2.8 화면 흐름도 렌더링·검토

2026-11-03 · 작성: 성윤우 / 도구: Codex, Mermaid 12.2.0, Chromium.

원본은 [디자인 3.4~3.6장](../09_DESIGN.md). [확대 검토본](screen-flows.html)은 외부 네트워크 없이 열리고 화면 이동·오류 복구 SVG 2개를 포함한다. 생성 SVG·PNG와 원본 일치 확인용 SHA-256은 [렌더링 기록](render-report-2.8.json)에 있다. 원본을 바꾸면 파생 그림도 다시 생성한다.

| 검토 | 결과 |
|---|---|
| 문법·실제 렌더링 | 기본 흐름·오류 복구 2개 모두 성공, 브라우저 오류0, 잘린 텍스트0 |
| UC-01~09 | 로그인·매장/재료/메뉴/입고/마감/사용폐기/현황/추천/발주 9개가 추적표 및 화면 경로와 대응 |
| 발주 상태 | 작성중→발주완료, 발주완료→작성중 되돌리기, 입고 후 사용자의 입고완료 표시를 그림에서 확인 |
| 사용자 확인 | AI 특선은 사용자가 검토·수정 후 등록. 복사는 사용자가 거래처에 전달, 자동 발송 없음 |
| 실패 복구 | 입력 유지·필드 오류, 인증 만료, 충돌 후 1회 재계획, 재실패 시 사용자 재시도 확인 |
| 범위 | UC-10·11 및 확장 기능을 필수 경로에서 제외. 기존 4장 와이어프레임 유지 |
| 읽기·접근성 | 한글·화살표·분기 라벨 확인, SVG 제목/설명 제공, HTML 확대50%와 375px 내부 스크롤 확인 |

관련: FR-AUTH-01~03, FR-ING-01~03·05, FR-MENU-01~02, FR-STK-01~04, FR-USE-01~05, FR-DASH-01~04, FR-REC-01~08, FR-ORD-01~05, BR-02·04·05·06. 에이전트 1차 검토와 렌더링 확인을 마쳤다. **사람 PR 리뷰/승인은 별도**이며 PR 병합 전까지 상태는 [~]다.
