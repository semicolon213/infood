# 11_TASK.md

작업 체크리스트와 완료 조건(DoD). 사람과 코딩 에이전트가 함께 쓴다.
작업 ID·공수·담당·선행 관계는 `04_WBS.md`, 날짜는 `05_일정표.md`, 요구사항 ID는 `03_SRS.md`를 따른다.

> 테스트 ID(UT-, IT-, E2E-)는 `10_TEST_PLAN.md` 기준이다. 이 문서는 11주차에 범위 변경에 맞춰 개정되므로, 개정 전에는 아래 DoD의 요구사항 ID로 판단한다.

## 사용 규칙
- 상태: `[ ]` 할 일 / `[~]` 진행 중(담당자 표기) / `[x]` 완료(PR 머지)
- 아래 **공통 DoD**와 작업별 DoD를 모두 만족해야 완료다.
- 에이전트는 한 번에 작업 ID 하나만 처리한다.
- AI 도구를 쓴 작업은 `docs/logs/ai-usage.md`에 한 줄 이상 기록한다.

## 공통 DoD
- `pnpm lint && pnpm typecheck && pnpm test` 통과
- PR 설명에 관련 요구사항 ID(FR-, NFR-, BR-)와 테스트 ID 기재
- UI 작업은 375×812 화면에서 확인
