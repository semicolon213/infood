# AI 활용 로그

> 취합: 성윤우 (WBS 1.3) · 결과는 AI 활용 검증 보고서(WBS 5.4)의 근거로 쓴다.
> 개발 중 AI 코딩 도구(Claude Code, Codex) 사용과 서비스의 AI 기능(메뉴 추천) 검증을 함께 기록한다.
> 기록 항목은 운영계획서 13절을 따른다: 일시 / 작업 단계 / 사용 도구 / 프롬프트 요지 / AI 응답 요지 / 채택·수정·폐기 여부와 이유 / 검증 방법과 결과.
> **작성 원칙:** 프롬프트 요지는 실제 입력한 요청을 뜻이 바뀌지 않게 문장만 다듬어 적는다. 팀이 내린 결정과 AI가 작성한 초안을 구분해 적는다.
