## 2. SOLID

| 원칙 | 점검 지점 | 결과 | 확인 |

| **OCP** | AI 공급자 추가 | 공급자 = `StructuredAdapter` 하위 클래스 + `client.ts` 선택 한 줄. Claude → Gemini 교체 때 추천·후처리·화면 변경 0줄 (#55). 보관일수 추천(4.6)·명세서 인식(4.7)도 같은 어댑터 재사용 | `adapters/*.test.ts`, `client.test.ts` |
| **DIP** | 기능 → AI SDK | 기능은 `AiClient` 추상에만 의존. SDK import는 `lib/ai/adapters` 안에만 (3장 R11 검색 0건) | `src/lib/ai/client.ts` |
| **DIP** | 어댑터 → SDK 호출 | SDK 호출 함수(`StructuredCall`)를 생성자로 주입 → 재시도·시간 제한·오류 변환을 API 키 없이 테스트 | UT-AI-03·10, `structured-timeout.test.ts` |
| **LSP** | `MockAdapter`를 실제 어댑터 자리에 | 고정 응답도 요청 스키마로 검증, 틀리면 같은 `AI_INVALID_OUTPUT` | UT-AI-09 |
| **ISP** | `AiClient`(메서드 1), `RecommendStrategy`(메서드 2) | 쓰는 쪽에 필요한 것만 있음 | - |
